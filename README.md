# ライフプラン・シミュレーター (Life Plan Simulator)

生涯にわたる収支・資産推移（現預金、新NISA、特定口座、従業員持株会）を可視化し、日本の現行税制・社会保険制度に基づいた高精度なキャッシュフロー分析を提供するWebアプリケーションです。

---

## 主な機能と特徴

### 1. 給与・昇給シミュレーションと税・社会保険料の自動計算
- **額面年収からの自動手取り計算**:
  - 給与所得控除（令和2年以降速算表準拠）
  - 社会保険料（健康保険、厚生年金、雇用保険、40歳以降の介護保険料）
  - 基礎控除、配偶者控除・配偶者特別控除、扶養控除（特定扶養63万円対応）
  - 所得税（5%〜45%超過累進税率 ＋ 復興特別所得税2.1%）および住民税（所得割10% ＋ 均等割）
- **昇給モデル**:
  - 現在年齢・年収から最高年収（ピーク年齢）まで均等昇給し、定年まで維持。
  - ボーナス割合（0〜50%）に応じた毎月の給与手取りと賞与手取りの按分計算。
- **手取り直接入力モード**: 確定している手取り額を直接入力することも可能。

### 2. 各種税金控除の完全対応
- **住宅ローン控除（税額控除）**:
  - 購入後13年間、年末残高の0.7%を控除（所得税控除後、引ききれない分は住民税から最大9.75万円まで控除）。
  - 省エネ適合住宅（4,000万限度）、認定長期優良住宅（4,500万限度）、一般住宅（3,000万限度）に対応。
- **ふるさと納税（特例控除）**: 自己負担2,000円を除いた全額を住民税・所得税から減税。
- **iDeCo / 企業型DC**: 全額所得控除として所得税・住民税を軽減。
- **生命保険料控除**: 一般・介護・年金保険料の所得控除。

### 3. 多彩な資産運用シミュレーション
- **新NISA制度準拠**:
  - 年間投資枠360万円、生涯投資枠1,800万円の上限管理。
  - 運用益・分配金は完全非課税（税率0%）。
- **特定口座**:
  - 運用益に対して20.315%の申告分離課税。新NISA枠超過分の自動スライド投資に対応。
- **従業員持株会**:
  - 会社の拠出金補助（奨励金・例: 10%）を毎月加算して複利運用。
  - 定年時の自動売却（譲渡益課税考慮）または運用継続を選択可能。
- **スポット臨時投資**: 結婚、住宅購入、相続などの特定年齢における臨時の一括投資設定。
- **生活防衛資金（現預金上限キャップ）**:
  - 現預金の上限額を設定し、超過した余剰資金を新NISAまたは特定口座へ全自動で投資に回すスイープ機能。

### 4. ライフイベント＆キャッシュフロー分析
- **住居**: 賃貸（更新料含む）／持ち家（頭金、固定資産税・修繕積立金、住宅ローン返済）。ボーナス返済比率と負担率警告機能。
- **マイカー**: 購入費用、買替サイクル、年間維持費。
- **家族・教育**: 子どもごとの誕生年齢・進学コース別（オール公立〜私立医歯薬系まで7コース対応）の教育費、児童手当の自動給付。
- **定年・老後**: 退職金、継続雇用（再雇用）、公的年金受給（本人の厚生年金＋基礎年金、配偶者年金）。
- **インフレ対応**: 物価上昇率を加味し、資産最大値の現在価値（割引後価値）も同時算出。

### 5. 高度なUI & データ管理
- **プリセット機能**: 「独身キャリア」「DINKS」「ファミリー」のワンクリック設定。
- **ブラウザ内自動保存 (LocalStorage)**: 入力値の変更を自動保存＆タブ間自動同期。
- **CSVエクスポート**: 年齢別キャッシュフロー明細表（資産収益額列含む）をCSV出力可能。
- **Chart.jsインタラクティブグラフ**: 資産推移（現金・NISA・特定・持株）および年間収支推移を視覚化。

## ローカルでの実行方法

本アプリは単一のHTML/JavaScriptファイルで完結しているため、外部サーバーやデータベースなしで動作します。

ブラウザで `index.html` を直接開くか、または簡易ローカルサーバーで起動できます:

```bash
# Pythonの場合
python3 -m http.server 8000

# Node.js (npx) の場合
npx serve .
```

ブラウザで `http://localhost:8000` にアクセスしてください。
